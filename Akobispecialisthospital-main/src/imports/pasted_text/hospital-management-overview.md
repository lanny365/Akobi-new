🏥 Hospital Management Software Story
Project Title: AKOBI Integrated Smart Hospital Management System (AISHMS)
________________________________________
1. 📌 Overview
Akobi Integrated Smart Hospital Management System (ISHMS) is a centralized digital platform designed to manage all operations of a modern hospital. It connects every department—Administration, Reception, Clinical, Pharmacy, Laboratory, Cashier, Accounts, Cleaning, and Maintenance—into one seamless system.
The goal is simple:
👉 Improve efficiency
👉 Reduce errors
👉 Increase revenue tracking
👉 Deliver better patient care
________________________________________
2. 🎯 Objectives
•	Automate hospital workflows
•	Provide real-time patient data access
•	Ensure financial transparency
•	Improve inter-department communication
•	Track staff activities (audit trail)
•	Enable data-driven decision making
________________________________________
3. 🏢 Core Departments & Functions
🧑💼 1. Administration Module
•	Create and manage users & roles
•	Assign permissions (Admin, Doctor, Cashier, etc.)
•	Monitor system activity (audit logs)
•	Configure hospital settings (wards, billing rates)
________________________________________
🛎️ 2. Reception Module
•	Patient registration (new & returning)
•	Capture full patient details:
o	Name, age, gender, phone, address
o	Next of kin
o	Patient ID / card number
•	Appointment scheduling
•	Queue management
________________________________________
🩺 3. Clinical Module
•	Doctor consultation interface
•	Record:
o	Symptoms
o	Diagnosis
o	Treatment plan
•	Prescriptions sent directly to pharmacy
•	Request lab tests
•	Patient history tracking
________________________________________
💊 4. Pharmacy Module
•	Receive prescriptions digitally
•	Dispense drugs
•	Drug inventory management:
o	Stock levels
o	Expiry tracking
•	Automatic stock deduction
•	Drug pricing & billing integration
________________________________________
🧪 5. Laboratory Module
•	Receive test requests from doctors
•	Record test results
•	Upload reports
•	Send results back to doctor dashboard
•	Maintain lab test history
________________________________________
💰 6. Cashier Module
•	Handle all payments:
o	Consultation fees
o	Lab tests
o	Drug purchases
•	Accept:
o	Cash
o	Bank transfer
o	POS/Card
•	Generate receipts
•	Update patient wallet
________________________________________
📊 7. Accounts Module
•	Financial reporting:
o	Daily income
o	Department revenue
•	Expense tracking
•	General ledger integration
•	Profit & loss reports
•	Bank reconciliation
________________________________________
🧹 8. Cleaning Module
•	Ward cleaning schedules
•	Staff assignment
•	Status tracking (cleaned / pending)
•	Hygiene reporting system
________________________________________
🛠️ 9. Maintenance Module
•	Equipment tracking
•	Fault reporting
•	Maintenance scheduling
•	Technician assignment
•	Service history logs
________________________________________
4. 🔄 System Workflow (Patient Journey)
1.	Patient arrives → Reception registers
2.	Patient sees Doctor (Clinical)
3.	Doctor:
o	Prescribes drugs → Pharmacy
o	Requests tests → Lab
4.	Lab performs tests → sends results
5.	Pharmacy dispenses medication
6.	Cashier processes all payments
7.	Accounts records transactions
8.	Cleaning & Maintenance ensure environment readiness
________________________________________
5. 🔐 Security & Access Control

•	Secure patient records

🧠 7. Theatre (Surgical) Module Overview
The Theatre Module manages all surgical operations within the hospital—from scheduling to execution and post-operation tracking.
It connects directly with:
•	Clinical (Doctors) 
•	Laboratory 
•	Pharmacy 
•	Accounts/Cashier 
________________________________________
🎯 Purpose of Theatre Module
•	Schedule surgeries 
•	Track patients undergoing operations 
•	Manage surgical teams 
•	Monitor theatre usage 
•	Record operation details 
•	Ensure proper billing 
________________________________________
🏗️ 2. Theatre Module Functions
🗓️ A. Surgery Scheduling
•	Book operation date & time 
•	Assign: 
o	Surgeon 
o	Nurses 
o	Theatre room 
•	Prevent double-booking 
________________________________________
🧑⚕️ B. Pre-Operation Preparation
•	Confirm: 
o	Patient details 
o	Diagnosis 
o	Lab results (VERY IMPORTANT) 
•	Verify payment status (optional rule) 
•	Generate surgery checklist 
________________________________________
🔪 C. Operation Management
•	Record: 
o	Type of surgery 
o	Start time & end time 
o	Surgeon notes 
o	Complications (if any) 
•	Track equipment used 
________________________________________
📋 D. Post-Operation Records
•	Operation outcome 
•	Recovery notes 
•	Doctor recommendations 
•	Transfer patient to ward 
________________________________________
💰 E. Theatre Billing
•	Surgery charges 
•	Equipment usage fees 
•	Staff fees 
•	Automatically sent to cashier
